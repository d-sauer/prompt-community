  <files>src/lib/github/mutations.ts</files>
  <behavior>
    - addLabelToIssue(token, issueNumber, labelName): calls REST POST /labels on issue, resolves void
    - removeLabelFromIssue(token, issueNumber, labelName): calls REST DELETE /labels/{name} on issue, resolves void
    - deleteIssueGraphQL(token, nodeId): calls GraphQL deleteIssue mutation with issueId (base64 node ID — NOT issue number), resolves void
    - postModerationComment(token, issueNumber, action, login): posts comment body `✓ {action} by @{login} on {YYYY-MM-DD}` via REST, resolves void
    - createRepoLabel(token, name, color, description): REST POST /repos/{owner}/{repo}/labels, resolves void
    - updateRepoLabel(token, oldName, newName, color, description): REST PATCH /repos/{owner}/{repo}/labels/{name}, resolves void
    - deleteRepoLabel(token, name): REST DELETE /repos/{owner}/{repo}/labels/{name}, resolves void
    - All REST calls include `headers: { 'X-GitHub-Api-Version': '2022-11-28' }` (project convention)
    - owner() and repo() helper pattern already in file — reuse
  </behavior>
  <action>
    Append to src/lib/github/mutations.ts (do not remove or modify existing functions).

    addLabelToIssue: POST /repos/{owner}/{repo}/issues/{issue_number}/labels with labels: [labelName]. Same shape as existing flagPrompt function.

    removeLabelFromIssue: DELETE /repos/{owner}/{repo}/issues/{issue_number}/labels/{name}. The label name must be URL-encoded in the path (e.g., `status:hidden` → use the name directly as Octokit handles encoding).

    deleteIssueGraphQL: GraphQL mutation `mutation DeleteIssue($issueId: ID!) { deleteIssue(input: { issueId: $issueId }) { repository { id } } }`. Use createGraphqlClient(token). Pass nodeId as issueId variable. CRITICAL: parameter is the GraphQL base64 node ID (the `id` field returned from GraphQL queries), not the integer issue number.

    postModerationComment: POST comment body `✓ {action} by @{login} on {date}`. date = new Date().toISOString().split('T')[0]. action is a string like "Approved", "Hidden", "Deleted", "Featured", "Unfeatured". Reuses REST POST /issues/{issue_number}/comments (same pattern as existing postComment function).

    createRepoLabel / updateRepoLabel / deleteRepoLabel: Use REST endpoints from research doc. Color stored as hex without `#`. updateRepoLabel passes `new_name` field (not `name`) in PATCH body.
  </action>
