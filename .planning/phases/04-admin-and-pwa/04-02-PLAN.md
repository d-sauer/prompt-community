  <behavior>
    useAdminStats:
    - useQuery({ queryKey: ['admin','stats'], queryFn }) calls GET_ADMIN_STATS GraphQL
    - Returns { total: Ref<number>, flagged: Ref<number>, featured: Ref<number>, isLoading: Ref<boolean> }

    useAdminQueue:
    - useInfiniteQuery or useQuery with page cursor for GET_FLAGGED_ISSUES (20/page)
    - Exposes: { items: Ref<FlaggedIssue[]>, isLoading, hasNextPage, fetchNextPage }
    - FlaggedIssue type: { id: string; number: number; title: string; createdAt: string; author: { login: string; avatarUrl: string }; labels: { name: string; color: string }[] }

    useAdminActions:
    - approveMutation: removeLabelFromIssue(flag:review) + postModerationComment('Approved', login)
    - hideMutation: addLabelToIssue(status:hidden) + postModerationComment('Hidden', login)
    - deleteMutation: deleteIssueGraphQL(nodeId) — accepts nodeId string (NOT issue number)
    - featureMutation: addLabelToIssue(status:featured) or removeLabelFromIssue(status:featured) based on current labels
    - bulkApproveMutation: accepts issueNumbers[], iterates sequentially calling approve for each
    - bulkHideMutation: accepts issueNumbers[], iterates sequentially calling hide for each
    - bulkDeleteMutation: accepts nodeIds[], iterates sequentially calling deleteIssueGraphQL for each
    - ALL onSuccess: invalidate ['admin','queue'] and ['admin','stats']

    useAdminLabels:
    - Fetches labels via getRepoLabels; groups by namespace prefix (split on first ':')
    - validateLabel(name: string): returns null if valid or error string if not matching /^[a-z][a-z0-9-]*:[a-z0-9][a-z0-9-]*$/
    - createLabel, updateLabel, deleteLabel mutations; createLabel/updateLabel call validateLabel before mutation — reject with error message if invalid (do not call API)
    - Returns: { groupedLabels, isLoading, validateLabel, createLabelMutation, updateLabelMutation, deleteLabelMutation, labelError: Ref<string | null> }

    useAdminLog:
    - Accepts: flagged issue list from useAdminQueue (or fetches independently)
    - For each issue, fetches REST comments via getIssueComments(token, issueNumber) — import from '@/lib/github/queries' (already defined in Plan 01, do NOT add to queries.ts again)
    - Filters to only comments matching /^✓ (Approved|Hidden|Deleted|Featured|Unfeatured) by @/
    - Parses each matching comment: action (word after ✓), promptTitle (issue title), maintainerLogin (login after @), timestamp (comment.created_at)
    - dateFrom / dateTo props filter entries client-side
    - Returns: { entries: Ref<LogEntry[]>, isLoading, dateFrom: Ref<string>, dateTo: Ref<string> }
    - LogEntry type: { timestamp: string; action: string; promptTitle: string; maintainerLogin: string; issueNumber: number }
