Wrangler commands (run from repo root, requires `wrangler login` / active session):

Step 1 — Provision D1 (one-time):
  npx wrangler d1 create prompt-community-db --config src/workers/api/wrangler.toml
  → Copy the output `database_id` UUID (e.g., "a1b2c3d4-e5f6-..."). You need this for wrangler.toml.

Step 2 — Update wrangler.toml with [env.production] block:
  Add to src/workers/api/wrangler.toml:

  [env.production]
  [env.production.vars]
  ENV = "production"
  APP_ORIGIN = "https://YOUR_PAGES_DOMAIN.pages.dev"

  [[env.production.d1_databases]]
  binding = "DB"
  database_name = "prompt-community-db"
  database_id = "REAL_UUID_FROM_STEP_1"
  migrations_dir = "db/migrations"

Step 3 — Apply migrations to production D1:
  npx wrangler d1 migrations apply prompt-community-db --config src/workers/api/wrangler.toml --remote --env production

Step 4 — Set secrets:
  npx wrangler secret put JWT_SECRET --config src/workers/api/wrangler.toml --env production
  npx wrangler secret put GITHUB_CLIENT_ID --config src/workers/api/wrangler.toml --env production
  npx wrangler secret put GITHUB_CLIENT_SECRET --config src/workers/api/wrangler.toml --env production

Step 5 — Deploy:
  npx wrangler deploy --config src/workers/api/wrangler.toml --env production

Step 6 — Smoke test (replace URL with actual worker URL from deploy output):
  curl https://prompt-community-api.YOUR_SUBDOMAIN.workers.dev/me
  → Expect: HTTP 401, body {"error":"Unauthorized"} or similar JSON

NOTE: D1 database IDs are NOT secrets — safe to commit to wrangler.toml.
NOTE: Set APP_ORIGIN to your Cloudflare Pages URL (the SPA host), not the worker URL.

    ```
    npx wrangler d1 execute prompt-community-db --command "SELECT name FROM sqlite_master WHERE type='table'" --remote --env production
    ```
