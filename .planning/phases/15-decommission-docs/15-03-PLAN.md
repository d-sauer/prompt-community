V2 Architecture Summary (for doc rewrites):
  Data: Cloudflare D1 (SQLite) with Drizzle ORM. Tables: users, prompts, prompt_tags,
        prompt_versions, comments, reactions, bookmarks, moderation_log, labels, notifications.
  API:  Hono worker deployed to Cloudflare Workers. Route modules per resource.
        All endpoints documented in REQUIREMENTS.md (API-01..28, AUTH-01..10).
  Auth: GitHub OAuth → server-side JWT (HS256, 7-day). HttpOnly + Secure + SameSite=Lax cookie.
        No GitHub token in browser. Role field in users table (user | maintainer).
  Search: D1 FTS5 virtual table (title + body). MiniSearch retained for offline PWA browsing.
  Caching: TanStack Query staleTime + standard HTTP cache headers. No ETag layer.
  Deploy: Cloudflare Pages (SPA) + Cloudflare Workers (API). Single-repo. No second data repo.
  Local dev: wrangler dev + npm run dev two-terminal workflow. /auth/dev-login (ENV=dev only).
  Two-repo model: ELIMINATED. prompt-community-data repository archived.

What CHANGED from v1:
  - GitHub Issues as DB → Cloudflare D1 + Drizzle ORM
  - Octokit GraphQL reads → REST API on Hono worker
  - GitHub access token in Pinia memory → JWT HttpOnly cookie
  - GitHub collaborators API for maintainer check → users.role field from D1
  - ETag conditional requests → TanStack Query staleTime
  - SPA + OAuth proxy worker + data repo (3 pieces) → SPA + API worker (2 pieces)
  - @octokit/core, @octokit/graphql (removed) → no GitHub API client in SPA
