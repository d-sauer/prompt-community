    - GET /prompts: returns { data: PromptSummary[], next_cursor: string | null }
    - Filter params: category, model, difficulty applied as WHERE clauses when present
    - sort param: 'newest' (default) = ORDER BY id DESC; other values ignored (use default)
    - Pagination: cursor param = last seen id, WHERE id < :cursor (DESC order), LIMIT :limit (default 20, max 100)
    - limit > 100: return 400 { error: 'invalid_limit', code: 'invalid_limit' }
    - Visibility: unauthenticated => status = 'published' only; authenticated optionalAuth user whose id matches author_id can also see their own drafts
    - Each PromptSummary has: id, title, category, model, difficulty, status, tags: string[], author: { login, avatar_url }, reaction_counts: { thumbs_up, heart, rocket }, comment_count, created_at, updated_at
    - When optionalAuth user present: add viewer_reaction (null | emoji string), viewer_bookmarked (boolean)
    - GET /prompts/:id: same as listing item but also includes body field
    - GET /prompts/:id with unknown id: 404 { error: 'not_found', code: 'not_found' }
    - GET /prompts/:id with 'flagged' or 'hidden' status: 404 (not visible)
  </behavior>
