<!-- FTS5 query pattern (D1 raw SQL — Drizzle cannot query virtual tables) -->

FTS5 table name: prompts_fts (from 0002_fts5.sql)
FTS5 indexed columns: title, body (tags are NOT indexed — see 0002_fts5.sql)

Raw D1 query pattern (use c.env.DB.prepare, not Drizzle, for FTS5):
```typescript
const rows = await c.env.DB.prepare(
  `SELECT p.id, p.title, p.category, p.model, p.difficulty, p.status, p.created_at, p.updated_at, p.author_id
   FROM prompts_fts
   JOIN prompts p ON p.rowid = prompts_fts.rowid
   WHERE prompts_fts MATCH ?
     AND p.status = 'published'
   ORDER BY rank
   LIMIT ?`
).bind(query, limit).all()
```

Note: CONTEXT.md says "Searches all three indexed fields: title, body, tags" but the FTS5 migration only indexes title and body (not tags). Search only title+body is correct per actual schema. SEARCH-01 is satisfied by the existing FTS5 table from Phase 9.

Labels schema: labels table has id, prefix, value, color, description
Labels grouped response (Claude's discretion from CONTEXT.md):
```typescript
{ categories: Label[], models: Label[], difficulties: Label[], tags: Label[] }
// grouped by prefix value
```

Notifications schema: notifications table has id, user_id, type, prompt_id, comment_id, read_at, created_at

requireAuth pattern from auth.ts:
