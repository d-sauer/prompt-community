    - Import { diffLines } from 'diff'

    - CRITICAL: normalize inputs: versionA.trim() and versionB.trim() before passing to diffLines (avoids Pitfall 7 trailing newline artifacts)
    - Split each change.value by '\n', filter trailing empty string (filter((_, i, arr) => i < arr.length - 1 || arr[arr.length - 1] !== ''))
    - Track lineNumberA and lineNumberB counters; increment based on type
    - Export DiffLine type

    usePromptVersions.ts:
    - TanStack useQuery with queryKey ['prompt-versions', issueNumber]
    - queryFn: calls createGraphqlClient(token) with GET_PROMPT_DETAIL or a dedicated versions query — fetch all issue comments (first: 100, ASC order)
    - Map comments through parseVersionComment(); filter out nulls silently (see Pitfall 6)
    - parseVersionComment(comment): apply VERSION_HEADER_RE, return null if no match, else return VersionObject
    - staleTime: 300_000 (5 minutes — version history changes less often than browse list)
    - enabled only when issueNumber is truthy

    useRestoreVersion.ts:
    - TanStack useMutation
    - mutationFn({ issueNumber, targetVersion: VersionObject, newVersionNumber: number }): call createVersionComment from mutations.ts with content = targetVersion.content, changelog = `Restored from Version ${targetVersion.version}`
    - onSuccess: queryClient.invalidateQueries(['prompt-versions', issueNumber]) and queryClient.invalidateQueries(['prompt', issueNumber])
    - Non-destructive: this only POSTS a new comment. It does NOT delete or alter the old comment.
