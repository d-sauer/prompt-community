Output: etag.ts (rewritten), octokit.ts (adapter wired), queries.ts (userLogin threaded), useAdminLabels.ts (clearEtag in onSuccess), useAuthStore.ts (clearUserEtags in logout), plus specs for all behaviors.

  <action>
    **etag.ts** — Rewrite in place. Remove the module-level Map. Implement:

    ```
    const STORAGE_KEY = (login: string) => `etag-cache:${login}`
    const MAX_ENTRIES = 50
    ```

    `readCache(login)`: localStorage.getItem → JSON.parse → new Map([entries]). try/catch returns new Map() on any error.

    `writeCache(login, map)`: JSON.stringify([...map.entries()]) → localStorage.setItem. try/catch swallows errors silently.

    `getEtag(login, key)`: readCache(login).get(key)

    `setEtag(login, key, value)`: readCache → cache.delete(key) [remove if exists, re-insert at end] → if (cache.size >= MAX_ENTRIES) { const firstKey = cache.keys().next().value; if (firstKey !== undefined) cache.delete(firstKey) } → cache.set(key, value) → writeCache

    `clearEtag(login, key)`: readCache → cache.delete(key) → writeCache

    `clearUserEtags(login)`: try { localStorage.removeItem(STORAGE_KEY(login)) } catch {}

    `etagFetchWrapper(url, options={}, cacheKey, userLogin)`: getEtag(userLogin, cacheKey) → build headers → fetch → getEtag from response → setEtag(userLogin, cacheKey, newEtag) if present → return response

    `makeBoundFetch(userLogin)`: returns (url: string, options: RequestInit = {}) => { const key = `${userLogin}:${new URL(url).pathname}`; return etagFetchWrapper(url, options, key, userLogin) }

    Export all: getEtag, setEtag, clearEtag, clearUserEtags, etagFetchWrapper, makeBoundFetch

    **octokit.ts** — Update createRestClient signature and body:
    ```typescript

          fetch: makeBoundFetch(userLogin),

      })

    ```
