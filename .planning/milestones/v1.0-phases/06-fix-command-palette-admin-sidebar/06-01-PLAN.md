<objective>
Wire the command palette search results and fix admin sidebar visibility. Two surgical integration gaps from the v1.0 audit:

1. `CommandDialog` in `Navbar.vue` opens on ⌘K but shows no results — `CommandList` is not connected to `useSearchStore`. Fix: bind native `@input` on `CommandInput` to call `searchStore.setQuery()`, render `CommandItem` list from `searchStore.results`, reset query on palette close.

2. Router guard in `router/index.ts` calls `verifyMaintainerStatus` on every `/admin` navigation but discards the result — `authStore.isMaintainer` stays `false` and the sidebar admin section never renders. Fix: write `authStore.isMaintainer = confirmed` before the redirect check.

Purpose: Closes SHEL-01 (global search functional) and ADMN-01 (maintainer panel access visible) — the last two pending v1 requirements before ETag caching (Phase 7).
Output: Updated Navbar.vue + router/index.ts with new unit tests proving each behavior.
</objective>
