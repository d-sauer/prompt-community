Access: Read = all, Restore = author/maintainer

Key Interactions

Select Version from List
Trigger:
User clicks a version item in the left panel
Action:
Set as right-side (version B) of diff; auto-select previous version as left (version A)
Visual:
Version item highlighted; diff view updates with new comparison
Change Comparing Versions
Trigger:
User changes Version A or Version B selector dropdowns
Action:
Compute diff between selected versions using jsdiff or custom algorithm
Render:
Update diff lines showing +/− changes
Restore Version
Trigger:
User clicks [Restore] button on a version (only for author/maintainer)
Guard:
ConfirmDialog: "Restore version N? A new version comment will be created."
Action:
useRestoreVersion(id, versionId) → POST new version comment with old content
Follow:
Invalidate usePromptVersions cache, navigate to /prompts/:id
Toggle Diff Mode
Trigger:
User clicks "Rendered" or "Raw" button
Action:
Switch useUIStore.diffMode between 'rendered' (diff view) and 'raw' (full content)
Visual:
Diff panel swaps to side-by-side raw markdown or full content preview
Toggle Diff Layout
Trigger:
User clicks "Side by Side" or "Unified" layout toggle
Action:
Switch useUIStore.diffLayout, re-render diff lines in new format
Visual:
Diff switches between two-column (side-by-side) or single-column (unified)
Load Versions on Mount
Trigger:
Component mounts with route param :id
Action:
usePromptVersions(id) → fetch all issue comments with "## Version" header
Render:
Populate version list, auto-select latest version for comparison
