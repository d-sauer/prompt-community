Tech Note

Master Search Input
Type to filter prompts via MiniSearch; real-time update; clear button resets
Input (shadcn); MiniSearch hook
Client-side search, no API call. Updates useSearchStore.query. Debounce optional for performance.
2
Active Filter Chips
Display current filters as removable chips; click × to clear that filter
Badge (shadcn); custom styling
One chip per active filter (category, model, etc.). Clicking × calls filter removal action; triggers query refetch.
3
Result Count
Display total number of prompts matching current filters
Text div
Updated in real-time from TanStack Vue Query data.length or metadata count.
4
Resize Handle
Drag left/right to resize split panels (240px–520px master, flex detail); stores position in UI store
ResizablePanelGroup (shadcn)
4px div with cursor: col-resize. Updates useUIStore.splitPanePosition on drag end. Persists to localStorage.
5
Reactions Bar
Toggle buttons (👍 42, ❤️ 15, 🚀 8); click to add/remove reaction; optimistic update
Button (shadcn, toggle variant)
Uses useToggleReaction(promptId, emoji) mutation. Updates local state immediately; syncs with API.
6
Comments List
Display all comments on the prompt; scroll to load more (virtual scroll); each comment shows avatar, author, time, text, reactions
ScrollArea (shadcn); virtual scroll optional
Fetched via useCommentsQuery(promptId). Paginated or infinite scroll. Comment count in header updates dynamically.
7
Comment Composer
Authenticated: avatar + textarea + Submit button. Unauthenticated: "Sign in to comment" CTA
Avatar, Textarea, Button (shadcn); conditional render
Controlled textarea; mutation useCreateComment(promptId, text) on submit. Clears field after success.
—
Prompt Rows (Master)
Click row to select/navigate to prompt; active row highlighted; hover state; shows avatar, author, time, title, tags, vote/comment counts
Avatar, Badge (shadcn)
Click handler navigates to /prompts/:id or updates usePromptsStore.selectedPromptId. Virtualized with TanStack Virtual.
—
Detail Header (Sticky)
Shows prompt title (truncated) and action buttons: Copy, Fork, History, Share, ⋯ (more)
Button (shadcn); sticky positioning
Copy button uses useClipboard() from @vueuse. Fork, History, Share navigate or open modals. ⋯ opens DropdownMenu.
