Key Interactions

Approve Flagged Prompt

User clicks [Approve] button on a flagged prompt. Row is optimistically removed from table. useRemoveLabelFromIssue mutation executes in background. If error, row re-appears and error toast displays.

useRemoveLabelFromIssue(issueId, 'state:flagged')

Hide Prompt (Moderation Action)

User clicks [Hide] button. Prompt receives state:hidden label and issue is closed. Row is optimistically removed. On success, toast shows "Prompt hidden & closed".

useAddLabelToIssue(issueId, 'state:hidden')
useCloseIssue(issueId)

Bulk Approve (Multiple Rows)

User checks multiple rows and clicks [Bulk Approve] from bottom action bar. All selected rows removed optimistically. Mutations execute in parallel via Promise.all. Bulk action bar disappears when all rows processed.

Promise.all(selectedIds.map(id => useRemoveLabelFromIssue(id, 'state:flagged')))

Add New Label (Label Manager Tab)

User fills inline form (color picker, name input, type selector). [Add Label] button submits. New label card appears instantly in grid. Input cleared. On error, toast shows message.

POST /repos/:owner/:repo/labels (via Octokit)

Tab Navigation with Deep Linking

Clicking a tab updates URL hash (#queue, #labels, #log, #featured). Users can bookmark deep links. Page refreshes to same tab via route handler.

router.push('/admin#queue')

Featured Prompts Tab

Displays all issues with state:featured label. [Remove from Featured] button removes label. Search input filters results and allows adding new featured prompts via useAddLabelToIssue.

useFeaturedPrompts() — @tanstack/vue-query hook
