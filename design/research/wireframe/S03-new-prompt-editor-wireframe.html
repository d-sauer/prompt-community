Key Interactions

Auto-save Draft
Trigger:
User types in any field; 30s debounce
Action:
POST to useDraftStore, set isDirty=true, save to localStorage
Visual:
Status badge updates to "Saved Xm ago"
Publish Prompt
Trigger:
User clicks [Publish] or presses ⌘↵
Action:
useCreatePrompt mutation → GitHub API creates issue with YAML frontmatter
Follow:
Invalidate usePrompts cache, navigate to /prompts/:newId
Image Upload
Trigger:
Drag image onto upload area or click to browse
Action:
POST to CF Worker /upload → returns public R2 URL
Insert:
Insert ![alt text](url) at cursor position in editor
Markdown Toolbar Button
Trigger:
User clicks toolbar button (e.g., Bold, Code)
Action:
If text selected: wrap in **text**; else insert ** at cursor
Preview:
Live markdown preview updates immediately
Link/Image Dialog
Trigger:
User presses ⌘K in editor or clicks Link button
Action:
Open Dialog component with URL input
Insert:
On confirm, insert [text](url) at cursor
Unsaved Changes Guard
Trigger:
User tries to navigate away with isDirty=true
Guard:
router.beforeEach → ConfirmDialog: "Save changes?"
Options:
Save, Discard, Cancel
