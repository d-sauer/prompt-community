# Element Behavior shadcn-vue Component Tech Note
1
 Profile Hero (Avatar, Name, Bio, Meta) Display user information from GitHub API. Avatar is 80px circle (GitHub avatar_url). Username links to GitHub profile in new tab. Bio from GitHub user.bio field. Avatar / AvatarImage / AvatarFallback, Card useUserProfile(username) hook; data fetched via @octokit/core REST /users/:username
2
 Edit Profile Button (Own Profile Only) Button visible only when viewing own profile. Clicking opens user's GitHub profile edit page in new tab. We don't manage profiles ourselves. Button Conditional render: if useAuthStore.user.login === routeParam.username, show button
3
 Stats Row (Prompts, Total Votes, Comments, Saved) Display 3–4 clickable stat items. Clicking a stat scrolls to/switches to corresponding tab. Stats are computed from prompt data and activity data. Last stat "Saved" only visible on own profile. Text + hover underline useUserPrompts(username) for count; @vueuse/core useTimeAgo for "Joined X ago"
4
 Tab Navigation (Submitted, Saved, Activity) Switch between prompt list, saved prompts, and activity tabs. "Saved" tab only visible on own profile. Tab selection highlights active tab. Tabs / TabsList / TabsTrigger / TabsContent URL does not change; tab state stored in Vue component (reactive variable)
5
 Prompt Card Grid (2 Columns Desktop) Display user's submitted prompts in 2-column grid (responsive to 1 column on mobile). Each card shows title, category+model tags, vote count, comment count, date, brief excerpt. Clickable to navigate to /prompts/:id. Card useUserPrompts(username) hook; sort by date or votes via toggle

Key Interactions

Navigate to Prompt Detail

User clicks a prompt card in the grid. Triggers client-side router navigation to /prompts/:issueId. Prompt detail view loads with full content, comments, and voting interface.

router.push('/prompts/' + issueId)

Click Stat to Switch Tab

User clicks on a stat item (e.g., "24 Prompts" or "42 Comments"). Component scrolls to top and switches to corresponding tab (Submitted → Prompts, Activity → Activity tab).

activeTab.value = 'submitted' // or 'activity'

Save Prompt from Profile Card

User clicks a bookmark or save icon on a prompt card (or right-click context menu). Prompt ID is added to useLocalStorage 'savedPrompts'. Heart icon fills; visual feedback shows prompt was saved. List updates on "Saved" tab if viewing own profile.

const savedPrompts = useLocalStorage('savedPrompts', [])
savedPrompts.value.push(issueId)

Remove Saved Prompt

User clicks [Remove] button on a saved prompt card in the Saved tab. Prompt ID is removed from localStorage array. Card is optimistically removed from view. List updates instantly.

savedPrompts.value = savedPrompts.value.filter(id => id !== promptId)

Sort Submitted Prompts

User clicks sort toggle (Most Voted / Newest) above prompt grid. Prompts are re-sorted client-side or server re-queries useUserPrompts with updated sort parameter. Grid is re-rendered in new order.

sortBy.value = 'votes' // or 'date'
useUserPrompts(username, { sortBy: sortBy.value })

Visit GitHub Profile

User clicks username link (with ↗ icon) or [Edit Profile] button. Opens user's GitHub profile in new tab via window.open(githubProfileUrl, '_blank').

window.open(`https://github.com/${username}`, '_blank')

Load Profile for New User

User navigates to /users/newusername. Route param is read, useUserProfile(newusername) query is triggered. GitHub REST API fetches user details. Avatar, name, bio, stats are displayed. useUserPrompts(newusername) loads submitted prompts grid.

const { username } = route.params
const { data: profile } = useUserProfile(username)
